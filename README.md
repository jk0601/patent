# PDF 자료 검색기

내 PC에 흩어져 있는 PDF를 한곳에 모아 **자동으로 분류하고, 검색하고, 요약**해 주는 프로그램입니다.
모든 자료는 **내 PC 안의 데이터베이스**에만 저장되며, 화면은 인터넷 브라우저로 봅니다(인터넷 주소가 아니라 내 PC 안에서만 열리는 화면입니다).

- PDF 폴더를 고르면 하위 폴더까지 모두 읽어 데이터베이스에 넣습니다.
- 문서 내용을 보고 **신고·징계 / 광고심사 / 회원관리·추천 / 법령·회칙 / 회의·보고 / 공문·서신 / 계약·회계**로 자동 분류합니다. 분류 기준은 직접 바꿀 수 있습니다.
- 단어로 검색하면 **어느 문서의 몇 쪽**에 있는지 보여 주고, 누르면 원본 PDF의 그 쪽이 열립니다.
- 분류별·연도별 문서 수, 자주 나오는 단어를 보여 주고, 문서 목록을 엑셀(CSV)로 내보냅니다.
- **AI 키가 없어도** 위 기능과 간단 요약이 모두 동작합니다. AI 키를 넣으면 AI 요약, 자료 기반 질문 답변, 스캔본 글자 읽기가 추가됩니다.

---

## 1. 설치하고 실행하기 (처음 한 번, 윈도우 10/11)

1. 이 페이지 위쪽의 초록색 **`<> Code`** 버튼 → **Download ZIP** 을 누릅니다.
2. 내려받은 ZIP 파일을 마우스 오른쪽 버튼으로 눌러 **압축 풀기**를 합니다. (바탕화면이나 문서 폴더에 푸는 것을 권장합니다.)
3. 압축을 푼 폴더 안의 **`START_Windows.bat`** 을 두 번 클릭합니다.
   - "Windows의 PC 보호" 파란 창이 뜨면 **추가 정보 → 실행** 을 누르세요.
   - PC에 Python이 없으면 자동으로 설치합니다(5분 정도). 확인 창이 뜨면 **예**를 누르세요.
   - 처음 한 번은 필요한 부품을 설치하느라 1~3분 걸립니다.
4. 잠시 후 브라우저에 프로그램 화면이 자동으로 열립니다.

> 검은 창은 프로그램 본체입니다. **닫으면 프로그램이 꺼집니다.** 다 쓴 뒤에 닫으세요.

### 두 번째부터

`START_Windows.bat`을 두 번 클릭하기만 하면 바로 켜집니다. 이미 켜져 있으면 브라우저 창만 다시 열어 줍니다.

## 2. PDF 넣기

**시작** 화면에서 세 가지 방법 중 편한 것을 쓰세요.

| 방법 | 이렇게 하세요 |
|---|---|
| 폴더 통째로 | **폴더 고르기** → PDF가 있는 폴더 선택 → **가져오기**. 하위 폴더까지 모두 읽습니다. |
| 끌어다 놓기 | PDF 파일들을 화면의 점선 상자 위로 끌어다 놓습니다. |
| PDF넣는곳 폴더 | 프로그램 폴더 안 **PDF넣는곳** 에 파일을 복사하고 **새 파일 확인**을 누릅니다. |

- 한 번 등록한 폴더는 프로그램을 켤 때마다 **새 파일·바뀐 파일만** 자동으로 반영합니다. 원본 파일에서 지워진 문서는 목록에서도 빠집니다.
- 원본 PDF는 옮기거나 고치지 않습니다. 읽기만 합니다.

### 스캔본 PDF는?

종이를 스캔한 PDF는 글자가 아니라 그림이라서 검색이 되지 않습니다. 프로그램은 이런 파일을 **스캔본**으로 따로 표시합니다(문서 목록 → '스캔본만').
- AI 키가 있으면: 문서를 열고 **AI로 글자 읽기**를 누르면 글자를 읽어 넣습니다.
- AI 키가 없으면: 한컴오피스·Adobe Acrobat 등의 OCR(글자 인식) 기능으로 다시 저장한 뒤 넣어 주세요.

## 3. 화면 안내

| 메뉴 | 하는 일 |
|---|---|
| 시작 | PDF 넣기, 분류 현황, 등록된 폴더 |
| 검색 | 단어 검색. 여러 단어는 띄어쓰기로. '모든 단어 포함' / '하나라도 포함' 선택 |
| 문서 목록 | 분류·이름·날짜로 거르기. 문서를 누르면 상세 정보, 쪽별 본문, 요약, 분류 바꾸기 |
| 분석 | 분류별·연도별 문서 수, 자주 나오는 단어, 엑셀(CSV) 내보내기, 분류별 폴더로 사본 정리 |
| 질문하기 | 문장으로 질문하면 관련 문서와 대목을 찾아 줍니다. AI 키가 있으면 근거(문서·쪽)를 붙인 답도 써 줍니다 |
| 설정 | AI 키 넣기/지우기, AI 모델 선택, 분류 기준 바꾸기 |

### 분류 기준 바꾸기

설정 → 분류 기준에서 한 줄에 하나씩 `분류이름: 단어, 단어, 단어` 로 적고 **저장하고 다시 분류**를 누르세요.
문서 본문에 그 단어가 많이 나올수록, 파일 이름에 들어 있을수록 그 분류로 들어갑니다. 문서 화면에서 직접 바꾼 분류는 자동 분류가 덮어쓰지 않습니다.

## 4. AI 기능 (선택)

| | AI 키 없음 (기본) | AI 키 있음 |
|---|---|---|
| 가져오기·분류·검색·분석 | ✅ PC 안에서 | ✅ PC 안에서 (외부 전송 없음) |
| 요약 | 중요한 문장을 원문 그대로 골라 보여 줌 | AI가 한 줄 요약, 핵심 내용, 당사자, 날짜, 관련 조항을 정리 |
| 질문하기 | 관련 문서·대목을 찾아 보여 줌 | 관련 대목만 AI에 보내 근거를 붙인 답을 받음 |
| 스캔본 | 표시만 함 | AI가 글자를 읽어 넣음 |

- 키 만들기: <https://console.anthropic.com> 에서 회원가입 → API Keys → Create Key. 사용한 만큼 요금이 나옵니다.
- 키 넣기: 프로그램 **설정** → API 키 붙여 넣기 → **저장하고 연결 확인**.
- 키를 지우면 바로 Python만으로 동작하는 방식으로 돌아갑니다.

> ⚠️ **AI 버튼을 누를 때만** 해당 문서 내용이 인터넷을 통해 Anthropic(Claude)으로 전송됩니다. 누르기 전에 확인 창이 뜹니다.
> 개인정보나 미공개 사건이 담긴 문서는 기관의 보안 방침을 확인한 뒤 사용하세요.

## 5. 자주 묻는 질문

**Q. 브라우저가 안 열려요.**
검은 창에 나온 주소(예: `http://127.0.0.1:8765`)를 브라우저 주소창에 직접 입력하세요. 다른 프로그램이 같은 번호를 쓰고 있으면 자동으로 다른 번호(8766, 8767…)를 씁니다.

**Q. '폴더 고르기' 창이 안 보여요.**
다른 창 뒤에 숨어 있을 수 있습니다. 작업 표시줄을 확인하세요. 그래도 안 되면 파일 탐색기 주소창의 폴더 주소를 복사해 입력 칸에 붙여 넣으세요.

**Q. 다른 사람도 내 화면에 들어올 수 있나요?**
아니요. 이 프로그램은 내 PC 안에서만 열리도록(`127.0.0.1`) 만들어져 있습니다.

**Q. 데이터는 어디에 저장되나요? 지우려면?**
프로그램 폴더 안의 `data` 폴더에 저장됩니다(`pdf_db.sqlite3` 파일 하나가 데이터베이스입니다). `data` 폴더를 지우면 처음 상태로 돌아갑니다. 원본 PDF는 지워지지 않습니다.

**Q. 다른 PC로 옮기고 싶어요.**
프로그램 폴더를 통째로 복사하세요. 단, `.venv` 폴더는 빼고 복사한 뒤 새 PC에서 START 파일을 다시 실행하면 됩니다.

**Q. 회사 PC라 Python 자동 설치가 막혀요.**
전산 담당자에게 Python 3.12 설치를 요청하거나, 열리는 python.org 페이지에서 직접 설치하세요. 설치 첫 화면에서 **Add python.exe to PATH** 에 꼭 체크한 뒤 Install Now를 누르면 됩니다.

**Q. 오류가 나요.**
검은 창의 메시지를 사진으로 찍어 담당자에게 보내 주세요. 인터넷 연결을 확인하고 START 파일을 다시 실행하면 해결되는 경우가 많습니다.

## 6. 구성 (관리자용)

```
START_Windows.bat      윈도우 실행 파일 (Python 확인·설치 → 전용 환경(.venv) → 부품 설치 → 실행)
START_Mac.command      맥 실행 파일
app.py                 웹 서버 (Flask, 127.0.0.1 전용, 빈 포트 자동 선택, 브라우저 자동 열기)
pdfdb/store.py         SQLite 데이터베이스, 자동 분류, 검색 (FTS5 trigram + 2글자 검색은 LIKE)
pdfdb/importer.py      PDF 글자 추출 (PyMuPDF), 바뀐 파일만 다시 읽기
pdfdb/textutil.py      날짜 찾기, 자주 나오는 단어, AI 없이 하는 요약
pdfdb/ai.py            외부 AI(Anthropic Claude) 연결 — 키가 있을 때만 사용
default_categories.json 기본 분류 기준
web/                   화면 (HTML, CSS, JavaScript)
```

- 필요 환경: 윈도우 10/11, Python 3.9 이상(없으면 START 파일이 winget으로 3.12 자동 설치).
- 실행 중 만들어지는 `.venv/`, `data/`, `PDF넣는곳/`, `분류별_정리/` 는 GitHub에 올라가지 않습니다(`.gitignore`).
- 포트를 고정하려면 환경 변수 `PDFDB_PORT=9000` 을 지정하세요.

## 부록: 맥에서 쓰기

강의는 윈도우 기준이지만 맥에서도 동작합니다.

1. 윈도우와 같이 ZIP을 내려받아 압축을 풉니다.
2. 폴더 안의 **`START_Mac.command`** 를 두 번 클릭합니다.
   - "확인되지 않은 개발자" 경고가 뜨면, 파일을 **마우스 오른쪽 버튼(Control+클릭) → 열기 → 열기** 를 누르세요.
   - 그래도 안 열리면 터미널을 열고 `bash ` (bash 다음 한 칸 띄우기)를 입력한 뒤 파일을 터미널 창으로 끌어다 놓고 Enter를 누르세요.
   - Python이 없으면 python.org 다운로드 페이지가 열립니다. 설치 후 다시 실행하세요.
